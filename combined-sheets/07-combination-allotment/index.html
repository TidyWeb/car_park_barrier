Exercise 01

Five allotment plots are up for rent. Each plot is a dictionary and all five sit inside a list. A rod is an old measure of ground, still used on allotments.

Given

plots = [
    {"holder": "Olive Green", "rods": 5, "shed": False},
    {"holder": "Hazel Nutt", "rods": 9, "shed": True},
    {"holder": "Anna Conda", "rods": 3, "shed": True},
    {"holder": "Penny Less", "rods": 10, "shed": False},
    {"holder": "Otto Graf", "rods": 6, "shed": True},
]

Print the holder of the fourth plot, then the size of that same plot, then the size of the second plot. Three lines of output.

Expected output

Penny Less
10
9

Getting a second fact out of a plot you have already visited does not become shorter the second time. The plot has to be named again in full.

Stuck?

The first bracket picks a plot out of the list by its number. The second asks that plot for one of its fields by name. Counting starts at nought.

Exercise 03

Rent is £3 for every rod of ground. A shed adds a flat £5 on top of that.

Work out what Hazel Nutt owes and print the number on its own. No sentence yet.

Expected output

32

Nothing in the data holds the rent. It does not exist until you work it out.

Stuck?

Work out the ground first and put it in a variable of its own. The shed is a separate decision made afterwards, and it only ever adds.

Exercise 04

The committee wants to know who is paying the most this year, and how much that is.

Look back at Exercise 3 for the correct details for each plot.

Work through every plot and print one sentence naming the holder and the amount, with the money to two decimal places.

This is a “best so far” pass. Each plot produces one total, and the remembered winner changes only when the current total beats it.

* Just as 0 can initialise a number variable, "" can initialise a string variable. This is an empty string: a string with no characters yet, ready to be replaced when a plot becomes the new winner.

Expected output

Hazel Nutt owes the most, at £32.00.

The largest rent is not the largest plot. A plot can be beaten by a smaller one with a shed on it.

Stuck?

The final sentence needs two matching facts: a winning amount and the holder it belongs to. Keep those two pieces together as you examine the plots.

Still stuck?

Before the loop, give “best so far” an initial value that a real plot can beat, and leave a placeholder for its holder. Update the pair only when a new total wins.
