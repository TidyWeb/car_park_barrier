PYTHON · COMBINED PRACTICE

Carry Python’s shapeswith you into new stories

What this set is for

This is a series of shorter, self-contained practice exercises to help us get our use of Python into our muscle memory.

These sheets are for the point where a Python pattern feels familiar in one story, but still slips away when the names and facts change.

The shape stays steady while the world changes: library books, allotment plots, market stalls, boats, bus stops and hall bookings. Type the code, run it, check the output, and return to any page that still feels uncertain.

▸The four shapes

▣ Hold

Keep the values and collections in view.

◇ Decide

Choose a path using the truth in the data.

↻ Repeat

Work through items or stop at the right point.

▤ Package

Give useful steps a reusable name.

▸Choose a practice sheet

Start with 06 to put the route together around one set of facts. Use 07–11 as transfer practice: the setting changes, but the questions you ask of the data remain recognisable.
