Exercise 01

Five stops sit on the 14 bus route. Each stop is a dictionary and all five sit inside a list. Passengers is how many got on there this morning.

Given

stops = [
    {"location": "Mill Lane", "passengers": 14, "delay": False},
    {"location": "Beacon Hill", "passengers": 9, "delay": True},
    {"location": "Cross Keys", "passengers": 22, "delay": False},
    {"location": "Foundry Row", "passengers": 6, "delay": True},
    {"location": "Riverside", "passengers": 11, "delay": True},
]

Print the stop location name for the third stop, then the passenger count for that same stop, then the passenger count for the last one. Three lines of output.

Expected output

Cross Keys
22
11
Stuck?

The first bracket picks a stop out of the list by its number. The second asks that stop for one of its fields by key name. Here, "location" holds the stop location name. Counting starts at nought.

Exercise 02

A delayed stop gets flagged on the driver's board, so the depot needs to know which ones those are.

Reach in for the stop whose location is Cross Keys and print one sentence or the other, depending on what you find.

Expected output

Cross Keys is not delayed.
Stuck?

The value stored under "delay" is already True or False. An if can test it as it stands, and the else catches everything it does not.

Exercise 03

A fare is £2.50 a passenger.

Work out the takings at the stop whose location is Beacon Hill and print the number on its own. No sentence yet.

These takings are money, so show two digits after the decimal point. The expected result is 22.50, not 22.5.

Expected output

22.50

Nothing in the data holds the takings. It does not exist until you work it out.

Stuck?

Reach in for the passenger count, then multiply it by the fare. Because the result is money, give the displayed number two decimal places.

Exercise 04

The depot wants a list of just the delayed stops — not the whole route, only the ones that are running late.

Set up an empty list before the loop. Inside the loop, add a stop location name to it whenever "delay" is True. The loop itself prints nothing.

Then, after the loop has finished, print the new list.*

* Starting value: the value on the right gives a variable its starting kind of holder. Compare these three starting shapes: 

counting_var = 0   # can hold integers and floats
text_var = ""      # can hold text
list_var = []      # can hold list items

For this task, the list starts empty because the loop will add the delayed stop location names to it one at a time.

Expected output

['Beacon Hill', 'Foundry Row', 'Riverside']
Stuck?

Begin with a collection ready to receive names. Each delayed stop contributes one stop location name; keep the final print outside the loop.

Still stuck?

Three of the five stops are delayed. Cross Keys has the most passengers of all of them, but it is not delayed — do not let passenger count decide this one.
