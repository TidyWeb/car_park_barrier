Reference

The punctuation jobs

{ } makes the bundle. A quoted label, :, and a value make one fact. A comma separates facts.

Labels and values

Labels are text, so they are quoted. Values keep their real type: numbers are not quoted.

Take or put?

Brackets on the right of = take a value. Brackets on the left select a labelled place to put a value.

Print it whole

Printing a dictionary shows every label and value in the bundle. Python may display text with single quotes even if you typed double quotes.

SHEET 02 · SCALES

Buildinga bundle

One vehicle, connected facts

One vehicle has several connected facts, and they should travel together. A dictionary builds that labelled bundle; Sheet 03 reaches back into one once it exists. 

vehicle = {"reg": "AB12 CDE", "hours": 2}
print(vehicle)
{'reg': 'AB12 CDE', 'hours': 2}
{ }starts and ends the bundle"reg"the label — always text, always quoted:connects a label to its value,separates one fact from the next

The bundle keeps those labelled facts together until you need one of them.

The map

gather loose facts → build from a description → keep values real → recognise broken punctuation → add a fact later → gather many vehicles

Each exercise stands alone. Stop anywhere, come back later.

▸One vehicle, three separate names

Exercise 01

At the moment, the coding window gives you three separate variables for one vehicle:

Given

reg = "LT19 KFN"
hours = 4
fee = 4.5

If a second vehicle arrives, you need three more variable names to hold its different values: 

reg_two = "YB70 XCE"
hours_two = 6
fee_two = 16.5

You cannot use reg, hours, and fee again: that would replace the first vehicle’s values. Every extra vehicle means more separate names to keep track of.

Put the first vehicle’s three facts together into one dictionary called vehicle, then print it whole.

Expected output

{'reg': 'LT19 KFN', 'hours': 4, 'fee': 4.5}
Stuck?
The question

Which three labelled facts belong together?

The shape

vehicle = {"____": ____, "____": ____, "____": ____}

Working answer

Use the labels "reg", "hours", and "fee", then print vehicle.

Show a working answer 
vehicle = {"reg": reg, "hours": hours, "fee": fee}
print(vehicle)

Printing it whole shows every comma, colon, and label. Python displays text with single quotes even though double quotes were typed; both quote kinds mean text.

→A second bundle

Exercise 02

The first vehicle’s facts are now in one bundle. The second vehicle needs its own bundle — and this time the labels do not have to change.

Given

vehicle = {"reg": "LT19 KFN", "hours": 4, "fee": 4.5}

Build a second dictionary called vehicle_two from this description: 

YB70 XCE, stayed 6 hours, owes 16.50

Print it whole.

Expected output

{'reg': 'YB70 XCE', 'hours': 6, 'fee': 16.5}

The labels reg, hours and fee appear a second time and nothing is overwritten. They are labels inside a bundle, not names of their own, so each vehicle can use the same three.

The label that stored a fact is the label that fetches it back. The bundle first, then square brackets, then the label in quotes. 

print(vehicle["reg"])
LT19 KFN

Print the first vehicle’s registration and the second vehicle’s fee.

Expected output

LT19 KFN
16.5

Fetching facts back out has more to it than this, and that is what the next sheet covers.

Exercise 03

See it once

print("3" * 2)
print(3 * 2)
33
6

This should report double the hours the vehicle stayed. Run it first. Then fix the dictionary so it reports what it should. Do not change the print line.

Given

vehicle = {"reg": "PK21 RAV", "hours": "4"}

print(vehicle["hours"] * 2)

Expected output before the fix

44

Expected output after the fix

8
Stuck?
The question

Is the value for hours text, or is it a number?

The shape

"hours": ____

Working answer

Remove the quotes around 4. Do not change the label or the print line.

Show a working answer 
vehicle = {"reg": "PK21 RAV", "hours": 4}

print(vehicle["hours"] * 2)

No error is raised. Quotes made the value text, and text repeats instead of multiplying.

Read = right-side first. Work out the value on the right, then put it into the slot named on the left. The only change is that the slot is now inside a dictionary rather than a name of its own.

parcel = {"weight": 2}
parcel["zone"] = "local"
print(parcel)
{'weight': 2, 'zone': 'local'}

Work out the fee from hours and rate, put it into vehicle under the label "fee", then print the whole vehicle.

Given

vehicle = {"reg": "LT19 KFN", "hours": 4}
rate = 2.75

Expected output

{'reg': 'LT19 KFN', 'hours': 4, 'fee': 11.0}
Stuck?
The question

Which value must be worked out before it can be stored?

The shape

vehicle["____"] = vehicle["____"] * rate

Working answer

✓Gather many vehicles

Exercise 06

A new level: several vehicles

So far, one dictionary has represented one vehicle. Now we are moving one level outwards: we are practising how to hold several vehicle dictionaries together.

A dictionary answers, “What facts belong to this vehicle?” A list answers, “Which vehicles are in the car park?” We will first build three separate vehicle dictionaries, then gather those named dictionaries into a list. The full Car Park Barrier project will need one of these larger structures when it works through several vehicles.

First: build three individual vehicles

Build three separate dictionaries: one in vehicle_one, one in vehicle_two, and one in vehicle_three. Each variable should hold one complete vehicle dictionary: LT19 KFN, 4 hours; YB70 XCE, 6 hours; PK21 RAV, 1 hour.

Then: gather them into a list

Now gather those three named dictionaries into a list called vehicles. Put the variable names in the list; do not build three new dictionary literals at this stage. Print the first vehicle’s registration.

Vehicles keyed by registration

Finally, build the second shape in vehicles_by_reg: use each registration as the outside key and store its hours inside. Print the hours for LT19 KFN.

Expected output

LT19 KFN
4
Stuck?
The question

Build each vehicle dictionary first. Then ask: “What larger container should hold these three complete vehicles?”

The shape

vehicle_one = {"reg": "...", "hours": ...}
vehicle_two = {"reg": "...", "hours": ...}
vehicle_three = {"reg": "...", "hours": ...}

After those three lines, gather the named dictionaries: vehicles = [vehicle_one, vehicle_two, vehicle_three]

Working answer

The three variables hold the individual dictionaries. The list holds those variables. In the second structure, the registration moves to the outside as the key, so the lookup begins with vehicles_by_reg["LT19 KFN"].

Show a working answer 
vehicle_one = {"reg": "LT19 KFN", "hours": 4}
vehicle_two = {"reg": "YB70 XCE", "hours": 6}
vehicle_three = {"reg": "PK21 RAV", "hours": 1}

vehicles = [vehicle_one, vehicle_two, vehicle_three]
print(vehicles[0]["reg"])

vehicles_by_reg = {
    "LT19 KFN": {"hours": 4},
    "YB70 XCE": {"hours": 6},
    "PK21 RAV": {"hours": 1},
}
print(vehicles_by_reg["LT19 KFN"]["hours"])

Both shapes hold the same vehicles. Sheet 03 navigates them; Sheet 05 loops through them.

✓What this unlocks 

vehicles = [vehicle_one, vehicle_two, vehicle_three]

You have one list holding three dictionaries. Sheet 03 will show you how to move around inside it.
