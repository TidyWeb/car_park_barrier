Hints

What the f does

f before the quote turns the string into a template. Anything inside { } is worked out and dropped in. Without the f, you get the braces printed literally.

Dictionary keys need quotes

A dictionary key is text, so it needs quotes inside the square brackets: vehicle['reg']. Using the other quote kind from the outer f-string makes a crowded line easier to read.

Two digits for money

:.2f goes inside the braces after the value. £ goes outside the braces, as ordinary text.

Brackets have different jobs

{"reg": "LT19 KFN"} builds a dictionary. vehicle['reg'] reaches into it. Inside an f-string, {vehicle['reg']} means: work out that reach, then insert it into the line.

SHEET 01 · SCALES

Getting a valueinto a line

Scales, not a project

I love f-strings. I love them because they are difficult: they forced me to think about what I was putting on the page. Not only about the syntax, which can feel tortuous, but about how to break a line into components, using different brackets to hold different things. Practising that helped me.

These are short, repetitive and deliberately unexciting. The first exercise shows the full shape once; the next four isolate the part that tends to snag: reaching into a dictionary with the right brackets and quotes. Correct but slow is the middle stage, not the finish.

▸See the whole shape once

Worked example

name = "Marjorie"
spend = 18.4

print(f"{name} spent £{spend:.2f}")
Marjorie spent £18.40

The f makes the whole string a template.

{name} is replaced by the value; the text around it is printed as written.

£ sits outside the braces because it is text. :.2f sits inside because it is an instruction about the number.

✱Tier 1 · the shape, then the reach alone

Exercise 01

Print one line giving the registration, how long the vehicle stayed, and what it owes as money. This is the whole flat shape once. If it is not quick, return to the worked example before moving on.

Given

reg = "LT19 KFN"
hours = 4
fee = 4.5

Expected output

LT19 KFN stayed 4 hours and owes £4.50
Show a working answer
print(f"{reg} stayed {hours} hours and owes £{fee:.2f}")

Exercise 02

There is no f-string here. Print just the registration from the dictionary. The only new question is how to write the key inside the square brackets.

Given

vehicle = {"reg": "PK21 RAV", "fee": 3.2}

Expected output

PK21 RAV
Show a working answer
print(vehicle['reg'])

Exercise 03

Use the same shape to print just the fee. Nothing else changes; only the key does.

Given

vehicle = {"reg": "PK21 RAV", "fee": 3.2}

Expected output

3.2
Show a working answer
print(vehicle['fee'])

→Tier 2 · brackets, then company

Exercise 04

Create a dictionary named vehicle with registration LT19 KFN and fee 4.5. Then print just its registration. Curly brackets build the dictionary; square brackets reach back into it.

Expected output

LT19 KFN
Need a hint?
Hint 1

First create vehicle. The printed line comes after the dictionary exists.

Hint 2

Inside the dictionary, each fact has a quoted label, a colon, and its value.

Hint 3

Once it exists, use the same one-key reach as Exercise 02: the quoted label is 'reg'.

Show a working answer
vehicle = {"reg": "LT19 KFN", "fee": 4.5}
print(vehicle['reg'])

Exercise 05

The reach now moves inside an f-string. Print a line reading Vehicle: PK21 RAV. The square brackets still reach for the key; the curly braces tell the f-string to insert that reached value.

Given

vehicle = {"reg": "PK21 RAV", "fee": 3.2}

Expected output

Vehicle: PK21 RAV
Need a hint?
Hint 1

Only the registration changes in the sentence. The rest is ordinary text.

Hint 2

Start with the reach you already know: vehicle['reg'].

Hint 3

Put that reach inside { }, then put f before the opening quote.

Show a working answer
print(f"Vehicle: {vehicle['reg']}")

Exercise 06

All the facts are now in one dictionary. Print one line naming the vehicle and what it owes.

Given

vehicle = {"reg": "YB70 XCE", "fee": 12.0}

Expected output

YB70 XCE owes £12.00
Need a hint?
Hint 1

This sentence needs two changing facts from the same dictionary.

Hint 2

One reach gets the registration; the other gets the fee.

Hint 3

The money instruction belongs after the fee reach, inside its curly braces: :.2f.

Show a working answer
print(f"{vehicle['reg']} owes £{vehicle['fee']:.2f}")

✓Tier 3 · the trap, and cold

Exercise 07

This line is already written and it will not run. Before you press Run, decide what reg and fee mean to Python. Then run it, read the error, and fix it. Predicting an error is worth more than avoiding one; the rail’s dictionary-key hint is there if needed.

Given

vehicle = {"reg": "PK21 RAV", "fee": 3.2}

print(f"{vehicle[reg]} owes £{vehicle[fee]:.2f}")

Expected output once fixed

PK21 RAV owes £3.20
Need a hint?
Hint 1

Ask what Python thinks reg is when it has no quote marks.

Hint 2

Without quotes, Python reads reg as a variable name. Here it is meant to be a dictionary label.

Hint 3

Dictionary labels are text: put quote marks around both reg and fee inside the square brackets.

Show a working answer
print(f"{vehicle['reg']} owes £{vehicle['fee']:.2f}")

Exercise 08

The fee is not stored. It is the hours multiplied by the rate. Print one line showing the vehicle and what it owes, working the fee out as you print it.

Given

vehicle = {"reg": "LT19 KFN", "hours": 4}
rate = 2.75

Expected output

LT19 KFN owes £11.00
Need a hint?
Hint 1

The line has two jobs: show the registration and work out the fee.

Hint 2

hours belongs to vehicle; rate is already a named variable.

Hint 3

Calculate vehicle['hours'] * rate inside the second set of curly braces, then add :.2f.

Show a working answer
print(f"{vehicle['reg']} owes £{vehicle['hours'] * rate:.2f}")

Exercise 09

Print one line for each vehicle, giving its registration and what it owes. The fee is the hours multiplied by the rate. Money shows two digits.

It needs a loop, which is Sheet 05’s subject. That is intentional: three separate print lines are an acceptable answer here.

Given

vehicles = [
    {"reg": "LT19 KFN", "hours": 4},
    {"reg": "YB70 XCE", "hours": 6},
    {"reg": "PK21 RAV", "hours": 1},
]
rate = 2.75

Expected output

LT19 KFN owes £11.00
YB70 XCE owes £16.50
PK21 RAV owes £2.75
Need a hint?
Hint 1

This is the Exercise 08 shape repeated for each dictionary in vehicles.

Hint 2

A loop gives you one dictionary at a time. Call that one dictionary vehicle.

Hint 3

Inside the loop, use the same registration reach and hours-times-rate calculation as Exercise 08.

Show a working answer
for vehicle in vehicles:
    print(f"{vehicle['reg']} owes £{vehicle['hours'] * rate:.2f}")
