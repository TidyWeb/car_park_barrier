One question

if asks a question. Its indented lines run only when the answer is true.

A chain

A chain stops at its first true question. Ask the widest question last.

Independent decisions

Can both facts be true? Use two independent ifs. An elif would silently skip the second question.

One question inside another

If a second question matters only after the first answer, indent it inside the first one.

Check the limit

Use the value exactly on the limit to check whether you need > or >=.

Silent logic

Wrong logic prints the wrong sentence, or nothing at all. Python does not complain.

SHEET 04 · SCALES

Making adecision

A barrier has to decide something before it does anything. It asks questions in a chosen order, then runs the lines that fit the answer. 

height = 1.6

if height >= 2.0:
    print("Too tall for the barrier")
else:
    print("Barrier opening")
Barrier opening
ifasks a question that is either true or false:ends the questionindentthe lines that run only when the answer was trueelsewhat happens when it was not

Nothing on this sheet will raise an error. If the wrong sentence appears, or none appears at all, Python has done exactly what it was told.

Type one line and run it before writing the next one. The output tells you which line caused a mistake.

▸One question

Exercise 01

An if is a question. When the answer is false, its indented lines are skipped. Nothing happens: no message and no complaint.

Write an if statement whose question tests whether the vehicle’s height is over 2.0. If it is, print "Too tall for the barrier". Run it. Then change the height to 1.4 and run it again: nothing should appear.

Then add an else that prints "Barrier opening", and run both heights again.

Given

vehicle = {"reg": "YB70 XCE", "height": 2.4}

Expected output, tall

Too tall for the barrier

Expected output, low

Barrier opening
Stuck?

What comparison is true only when the stored height is above 2.0?

The shape 
if vehicle["height"] ____ 2.0:
    print("Too tall for the barrier")
else:
    print("Barrier opening")
Working answer 
if vehicle["height"] > 2.0:
    print("Too tall for the barrier")
else:
    print("Barrier opening")

→A chain chooses one answer

Exercise 02

When questions are chained, Python asks them from the top and stops at the first true one. Everything below is skipped, however true it might be.

A five-hour stay should use the long stay rate, but this code prints the standard rate. Reorder the questions so it is right.

Given

stay = 5

if stay > 1:
    print("Standard rate")
elif stay > 4:
    print("Long stay rate")
else:
    print("Free")

Expected output

Long stay rate

The widest question is asked last, because it catches everything that reaches it.

Stuck?

Which question must come first so that a five-hour stay does not stop at the standard rate?

The shape 
if stay ____ 4:
    print("Long stay rate")
elif stay ____ 1:
    print("Standard rate")
else:
    print("Free")
Working answer 
if stay > 4:
    print("Long stay rate")
elif stay > 1:
    print("Standard rate")
else:
    print("Free")

+Independent decisions

Exercise 04

An elif belongs to one question with several possible answers. Two questions that have nothing to do with each other each need their own if. Chaining them loses one without saying so.

Both facts are true of this vehicle, but the supplied chain reports only one. Separate the questions so both messages appear.

Given

vehicle = {"reg": "LT19 KFN", "height": 2.4, "permit": False}

if vehicle["height"] > 2.0:
    print("Use the side entrance")
elif vehicle["permit"] == False:
    print("Pay at the machine")

Expected output

Use the side entrance
Pay at the machine

If both could be true at once, they are separate questions. If only one can ever be true, they belong in one chain.

Stuck?

Could a tall vehicle also have no permit?

The shape 
if vehicle["height"] > 2.0:
    print("Use the side entrance")

if vehicle["permit"] == ____:
    print("Pay at the machine")
Working answer 
if vehicle["height"] > 2.0:
    print("Use the side entrance")

if vehicle["permit"] == False:
    print("Pay at the machine")

Every decision on this sheet was one of two shapes: a chain that picks a single answer, or separate questions that each stand on their own.

Nothing here raised an error. A wrong answer looks exactly like a right one until the output is read. The next sheet removes the repetition.
