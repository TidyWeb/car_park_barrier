Reference

One item per pass

The indented lines run once for every item. The loop variable is the one item currently in hand.

Name the two layers

Use a plural name for the collection and a singular name for the loop variable: vehicles and vehicle.

A running total

Set it up before the loop, add to it inside, then read it after the loop.

Keep a pair together

When a value and the item it belongs to change together, replace both in the same if.

A loop inside a loop

The inner loop finishes completely before the outer loop moves to its next item.

One total or many?

A total for every vehicle starts inside the outer loop. A total for all vehicles starts before it.

Doing the samejob for each

Three vehicles need the same three questions. Written out by hand, that is nine near-identical lines. A fourth vehicle would make twelve. 

registrations = ["AB12 CDE", "FG34 HIJ"]

for registration in registrations:
    print(registration)
AB12 CDE
FG34 HIJ

Earlier sheets made you type the same shape again and again. One loop now covers a collection of any size.

Type one line and run it before writing the next. A loop that is nearly right produces output that is nearly right, and it is easier to see which line caused it while there is only one line to inspect.

The map

one item→dictionaries→a conditional→a running total→the largest→nested loops→everything together

Exercise 01

The indented lines run once for each item in the collection. The loop variable holds a different item each time round.

Print each registration on its own line.

Given

registrations = ["LT19 KFN", "YB70 XCE", "PK21 RAV"]

Expected output

LT19 KFN
YB70 XCE
PK21 RAV

The collection is plural because it holds several. The loop variable is singular because it holds one.

Stuck?

The shape 
for ____ in registrations:
    print(____)
Working answer

    print(registration)

Exercise 02

When the collection holds dictionaries, the loop variable holds one whole dictionary each time round. Reach into it exactly as before.

Print one line per vehicle giving its registration and what it owes. The first hour is free; every hour after that costs £2. Show money to two digits.

Given

vehicles = [
    {"reg": "LT19 KFN", "hours": 4},
    {"reg": "YB70 XCE", "hours": 6},

]

Expected output

LT19 KFN owes £6.00
YB70 XCE owes £10.00
PK21 RAV owes £0.00

This is the same output the first sheet needed three separate lines to produce. A fourth vehicle now needs no new code.

Stuck?

What does vehicle hold on one pass: the whole list, or one dictionary from it?

for vehicle in vehicles:

for vehicle in vehicles:
    print(f"{vehicle['reg']} owes £{(vehicle['hours'] - 1) * 2:.2f}")

Exercise 03

An if can sit inside a loop. The if line is indented once because it belongs to the loop. Its print is indented twice because it belongs to both.

Print a line only for vehicles over 2.0 metres, in this form: PK21 RAV sent to the side entrance.

Given

vehicles = [
    {"reg": "LT19 KFN", "height": 2.0},
    {"reg": "YB70 XCE", "height": 1.6},
    {"reg": "PK21 RAV", "height": 2.4},
]

Expected output

PK21 RAV sent to the side entrance
Stuck?

Which vehicle has a height strictly above 2.0?

The shape 
for vehicle in vehicles:

Working answer

+Takings and refusals

Exercise 04

One loop can keep two answers growing. Takings add a money value. Refusals add one each time a vehicle is too tall.

The first hour is free. Every hour after that costs £2.

Print the total taken and the number of vehicles refused.

Given

vehicles = [
    {"reg": "LT19 KFN", "hours": 4, "height": 1.4},
    {"reg": "YB70 XCE", "hours": 6, "height": 2.4},
    {"reg": "PK21 RAV", "hours": 1, "height": 1.6},
]

Expected output

Total taken: £6.00
Refused: 1
Stuck?

Both answers start before the loop. The refusal count changes only inside the height question.

The shape 
total_taken = 0
refused = 0
for vehicle in vehicles:
    if vehicle["height"] >= 2.0:
        refused = refused + 1
    else:
        fee = (vehicle["hours"] - 1) * 2
        total_taken = total_taken + fee
Working answer 
total_taken = 0
refused = 0
for vehicle in vehicles:
    if vehicle["height"] >= 2.0:
        refused = refused + 1
    else:
        fee = (vehicle["hours"] - 1) * 2
        total_taken = total_taken + fee

print(f"Total taken: £{total_taken:.2f}")
print(f"Refused: {refused}")

↑Keep the tallest pair together

Exercise 05

Finding the largest height needs two names kept in step: the height itself and the registration it belonged to. When a taller vehicle appears, replace both together, or the answer will name the wrong vehicle. 

numbers = [4, 7]
largest = 0

for number in numbers:
    if number > largest:
        largest = number

print(largest)
7

Start with a height of 0, because every vehicle height here is above it. Start the registration as an empty string because it has no value until the first taller vehicle is found.

Print the registration of the tallest vehicle and its height.

Given

vehicles = [
    {"reg": "LT19 KFN", "height": 2.0},

]

Expected output

Tallest: PK21 RAV at 2.4m

The shape 
tallest_height = 0
tallest_reg = ""
for vehicle in vehicles:

Exercise 07

Use one loop for every vehicle. Work out and print each fee, print the side-entrance message when needed, add every fee to the total, and count every vehicle with no permit. Print the two final answers after the loop.

has_permit is a simple true-or-false fact here. It is not the permit dictionary from Sheet 04.

Given

vehicles = [
    {"reg": "LT19 KFN", "hours": 4, "height": 2.0, "has_permit": False},
    {"reg": "YB70 XCE", "hours": 6, "height": 1.6, "has_permit": True},
    {"reg": "PK21 RAV", "hours": 1, "height": 2.4, "has_permit": False},
]

Expected output

LT19 KFN owes £6.00
YB70 XCE owes £10.00
PK21 RAV owes £0.00
PK21 RAV sent to the side entrance
Total taken: £16.00
Vehicles with no permit: 2
Stuck?

Which two names need to start at zero before the loop: the money total and the permit count?

The shape 
total_taken = 0
no_permit_count = 0
for vehicle in vehicles:
    fee = (vehicle["hours"] - 1) * 2
    print(f"{vehicle['reg']} owes £{fee:.2f}")
    if vehicle["height"] > 2.0:
        print(f"{vehicle['reg']} sent to the side entrance")
    if vehicle["has_permit"] == ____:
        no_permit_count = no_permit_count + 1
    total_taken = total_taken + fee
Working answer 
total_taken = 0
no_permit_count = 0

for vehicle in vehicles:
    fee = (vehicle["hours"] - 1) * 2
    print(f"{vehicle['reg']} owes £{fee:.2f}")
    if vehicle["height"] > 2.0:
        print(f"{vehicle['reg']} sent to the side entrance")
    if vehicle["has_permit"] == False:
        no_permit_count = no_permit_count + 1
    total_taken = total_taken + fee

print(f"Total taken: £{total_taken:.2f}")
print(f"Vehicles with no permit: {no_permit_count}")

day_total = 0

for customer in customers:
    basket_total = 0
    for price in customer["basket"].values():
        basket_total = basket_total + price
    day_total = day_total + basket_total
    print(f"{customer['name']}: £{basket_total:.2f}")

print(f"Day total: £{day_total:.2f}")

It is the Exercise 06 shape: a loop inside a loop, one total for each customer and one total across all of them.
