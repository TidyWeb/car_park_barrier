Reference

Number or name?

A number asks a list for a position. A quoted name asks a dictionary for a labelled fact.

Read inside-out

Each bracket gives you something new to hold. Ask what that thing is before writing the next bracket.

Quotes mean text

"reg" means the label itself. Without quotes, Python looks for a variable named reg.

What errors tell you

IndexError: no such position. KeyError: no such label. TypeError: the question does not fit the thing you reached.

SHEET 03 · SCALES

Reachinginto data

This sheet is repetitive on purpose. You are training one small movement until it comes out without thinking, and that means doing it more times than feels interesting. It gets worse before it gets better. Stick with it.

The map

position or label→two brackets deep→repeat the full address→name one vehicle→calculate one charge→diagnose a wrong question→navigate cold

Each exercise stands alone. Stop anywhere, come back later.

One bracket, two questions

Lists count from zero: 0 means the first vehicle, 1 the second. A number in square brackets asks for a position. A quoted name in square brackets asks for a label.

You do not have to build anything on this sheet. The lists and dictionaries are provided so you can concentrate on reaching into them. This sheet uses bare print(...) throughout: no f-strings here.

▸Position, then label

Exercise 01

The same square brackets ask two different questions, depending on what is inside them. First reach for a whole vehicle by position; then ask that vehicle for its registration.

Use two print commands: first print the whole first vehicle; then print the first vehicle’s registration.

Given

vehicles = [
    {"reg": "LT19 KFN", "hours": 4},
    {"reg": "YB70 XCE", "hours": 6},
    {"reg": "PK21 RAV", "hours": 1},
]

Expected output

{'reg': 'LT19 KFN', 'hours': 4}
LT19 KFN
Stuck?
The question

Which number means the first position in a list?

The shape

print(vehicles[____])

Working answer

Use 0 for the first vehicle. Then add ["reg"] to ask it for the registration.

Show a working answer 
print(vehicles[0])
print(vehicles[0]["reg"])

→Two deep, moving around

Exercise 02

The first bracket hands you a whole vehicle. The second asks that vehicle a question. Read it inside-out: get the vehicle, then get the fact.

Use three print commands, one for each requested value: the first vehicle’s registration; the third vehicle’s hours; the second vehicle’s registration.

Given

vehicles = [
    {"reg": "LT19 KFN", "hours": 4},
    {"reg": "YB70 XCE", "hours": 6},
    {"reg": "PK21 RAV", "hours": 1},
]

Expected output

LT19 KFN
1
YB70 XCE
Stuck?
The question

Count the position first. Then ask for the named fact from that one vehicle.

The shape

print(vehicles[____]["____"])

Working answer

List positions are 0, 1, then 2; the labels are "reg" and "hours".

Show a working answer 
print(vehicles[0]["reg"])
print(vehicles[2]["hours"])
print(vehicles[1]["reg"])

✱The same vehicle, three ways

Exercise 03

Same reach, the same vehicle, three different things to retrieve. Type the full address each time.

This one repeats the same route on purpose. Rather than typing all three lines and then running, type one print line, hit Run, and look at what comes back. Check it against the expected output. If it is wrong, you know exactly which line caused it. Then type the next one.

Finding a mistake on the line that made it is far easier than typing the whole block and hunting for the fault afterwards.

Use three print commands to print the second vehicle’s registration, its hours, then the whole second vehicle, each on its own line.

Given

vehicles = [
    {"reg": "LT19 KFN", "hours": 4},
    {"reg": "YB70 XCE", "hours": 6},
    {"reg": "PK21 RAV", "hours": 1},
]

Expected output

YB70 XCE
6
{'reg': 'YB70 XCE', 'hours': 6}
Show a working answer 
print(vehicles[1]["reg"])
print(vehicles[1]["hours"])
print(vehicles[1])

→Give it a shorter name

Exercise 04

That was tedious. Every line repeated the same first half before getting to the part that actually differed.

Two things fix it.

Pull the vehicle out once, into a name of its own:

vehicle = vehicles[1]

Then print takes several things at once, separated by commas, and puts a space between them: 

print(vehicle["reg"], vehicle["hours"])

Two long lines become two short ones.

Given

vehicles = [
    {"reg": "LT19 KFN", "hours": 4},
    {"reg": "YB70 XCE", "hours": 6},
    {"reg": "PK21 RAV", "hours": 1},
]

Expected output

YB70 XCE 6
Stuck?
The question

Which position gave you these facts in Exercise 03?

The shape

vehicle = vehicles[____]

Working answer

After that first line, use one print with the two facts, separated by commas.

Show a working answer 
vehicle = vehicles[1]
print(vehicle["reg"], vehicle["hours"])

↓Calculate a charge

Exercise 05

The first hour is free. Each hour after that costs £2. Work out what LT19 KFN owes from each of these two supplied shapes.

Use two print commands. First reach LT19 KFN in the list; then reach it in the dictionary keyed by registration. Calculate its fee both times and print the number. Do not use an f-string.

List of vehicles

vehicles = [
    {"reg": "LT19 KFN", "hours": 4},
    {"reg": "YB70 XCE", "hours": 6},
    {"reg": "PK21 RAV", "hours": 1},
]

Vehicles keyed by registration

vehicles_by_reg = {
    "LT19 KFN": {"hours": 4},
    "YB70 XCE": {"hours": 6},
    "PK21 RAV": {"hours": 1},
}

Expected output

6
6
Stuck?
The question

Get the hours first. The first hour is free, so subtract one before multiplying by 2.

The shape

print((vehicles[____]["hours"] - 1) * 2)

Working answer

In the keyed dictionary, the registration replaces the list position: vehicles_by_reg["LT19 KFN"]["hours"].

Show a working answer 
print((vehicles[0]["hours"] - 1) * 2)
print((vehicles_by_reg["LT19 KFN"]["hours"] - 1) * 2)

!Ask the wrong question

Exercise 06

Each reach can fail because it asks the wrong question. Predict what will go wrong, then remove the # from one line at a time and run it.

For each line, read the error and say whether the position, label, or type of thing being questioned is wrong.

Given

vehicles = [
    {"reg": "LT19 KFN", "hours": 4},
    {"reg": "YB70 XCE", "hours": 6},
    {"reg": "PK21 RAV", "hours": 1},
]

# print(vehicles[5])
# print(vehicles[0]["registration"])
# print(vehicles[0]["reg"]["hours"])
# print(vehicles["0"])
Stuck?
The question

Before each bracket, ask what kind of thing you are holding: list, dictionary, or text.

The shape

A list accepts a number. A dictionary accepts a quoted label. Text does not contain vehicle facts.

Working answer

Try one line at a time. The errors are two TypeErrors, one IndexError, and one KeyError.

What each error means

vehicles[5]: no sixth position. vehicles[0]["registration"]: no label with that name. vehicles[0]["reg"]["hours"]: the registration is text, not another vehicle. vehicles["0"]: a list needs a number, not a quoted label.

✓Navigate cold

Exercise 07

This structure has not appeared before, but every reach is familiar. Read one bracket at a time and keep asking what you now hold.

Use three print commands to print the customer’s name, the number of apples in their basket, and their second recent visit, each on its own line.

Given

customer = {
    "name": "Marjorie",
    "basket": {"apples": 4, "pears": 2},
    "recent_visits": ["Monday", "Thursday"],
}

Expected output

Marjorie
4
Thursday
Stuck?
The question

The customer is a dictionary. "basket" gives another dictionary; "recent_visits" gives a list.

The shape

print(customer["____"]) then add another bracket only when the first reach gives a container.

Working answer

The labels you need are "name", "basket", "apples", and "recent_visits". The second list position is 1.

Show a working answer 
print(customer["name"])
print(customer["basket"]["apples"])
print(customer["recent_visits"][1])

✓What this unlocks

Each bracket travels one level down. This is a complete address: customer → basket → apples. 

customer = {"basket": {"apples": 4}}
print(customer["basket"]["apples"])
4
